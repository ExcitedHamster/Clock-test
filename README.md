# Clock-test
A clock that supports 12 and 24 hour format side-by-side. Allowing user to add time 


What did you do particularly well?
I was able to discover how to show both clocks at the exact same time and when they update equally

Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?
I would like to be able to make classes. One for the 12 hour and the other for the 24 hour into separate files for compile/clock speed.

Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?
Figuring out how to set the correct display view for the clocks was one of the most difficult parts. They were either off-center, missing characters, buggy. It was aggrevating. Google was honestly 
my best friend along with stackoverflow

What skills from this project will be particularly transferable to other projects or course work?
Being able to debug, utilize accessor, and mutator methods. Having validation functions as well.

How did you make this program maintainable, readable, and adaptable?
By using whitespace where I could and adding comments to functions and what I believe may be confusing code that doesn't immediately stand out to someone.
